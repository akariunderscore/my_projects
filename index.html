chipped dice

65536 bytes out of crypto.getRandomValues, in your browser, one byte per pixel. it should look like static. if it looks like anything else, something is Very Wrong

what this is: a way to look. row y, column x is byte number y*256+x, drawn as grey level 0..255. tests (histogram, monobit, runs, the pair plot) are coming soon™

what this isn't: an audit. a good backdoored generator looks exactly like static to every test on this page, that's the whole point of it being good. what eyeballs and boring stats can catch is a missing face on the die, a stuck bit, a value that never shows up. that's a much smaller claim, but it's the one you can check yourself
